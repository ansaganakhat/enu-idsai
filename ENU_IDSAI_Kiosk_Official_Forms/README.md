# ENU · IDSAI Student Services — Official Forms Edition

Бұл нұсқада өтініштер бөлімі пайдаланушы ұсынған PDF бланкілерінің негізінде қайта жасалды.

## Негізгі өзгеріс

Алдыңғы нұсқада өтініштер HTML арқылы қайта теріліп, кейбір принтерлерде A4 бетінде кішірейіп немесе арақашықтықтары өзгеріп шығатын. Бұл нұсқада ресми PDF — layout үшін **source of truth**.

Жүйе PDF беттерін векторлық SVG ретінде көрсетеді және A4 өлшемінде тікелей басып шығарады. PDF-тегі сызықтар анықталған жерлерге онлайн толтыру өрістері қабат ретінде қойылады.

## Өтініштер

- Каталог: 33 студенттік бланк.
- RU/KK variant mapping: 66.
- Баспа беттері: 68.
- Онлайн толтыру үшін анықталған өрістер: 646.
- Күрделі кестелік немесе қол қою бланкілерінде онлайн өріс болмауы мүмкін; мұндай бланк ресми PDF күйінде басылады.

## Файлдар

- `forms/pdf/` — сайттағы әр өтінішке арналған ресми PDF.
- `forms/svg/` — дәл сол беттердің print-quality векторлық көрінісі.
- `official-forms-data.js` — қай өтініш қай PDF бетіне сәйкес келетінін және онлайн өрістер координаттарын сақтайды.
- `source/official-pdf-forms.zip` — пайдаланушы берген бастапқы PDF архиві.
- `FORMS_SOURCE_REVIEW.md` — Student Services каталогына кірмеген қызметтік құжаттар туралы түсіндірме.
- `PRINT_VALIDATION.txt` — A4/page asset QA нәтижесі.

## Іске қосу

GitHub Pages үшін repository root ішінде `index.html` болуы жеткілікті.

Windows kiosk аппараты үшін:

1. Архивті папкаға шығарыңыз.
2. `launch-kiosk.bat` іске қосыңыз.
3. Edge толық экран kiosk режимінде ашылады.

## Жаңа PDF ауыстырғанда

Бланк PDF өзгерсе, `official-forms-data.js` пен SVG беттерін қайта генерациялау қажет. Қазіргі нұсқада source archive сол үшін `source/official-pdf-forms.zip` ішінде сақталған.
