# Басып шығару / Печать

Өтініштер енді қайта терілген HTML макеттерінен емес, пайдаланушы берген ресми PDF файлдарынан шығарылады.

- Portrait бланктер: нақты A4 `210 × 297 mm`.
- Обходной лист: нақты A4 landscape `297 × 210 mm`.
- `scale()`, `zoom()` және автоматты кішірейту қолданылмайды.
- PDF беті векторлық SVG ретінде көрсетіледі, сондықтан мәтін баспа кезінде анық қалады.
- Онлайн толтырылған көгілдір өрістер print кезінде ақ фонға ауысып, кәдімгі қара мәтінмен шығады.
- Браузердің интерфейсі, сайт header-і және көмекші блоктар қағазға шықпайды.
- `document.title` print кезінде босатылады және `@page margin:0` қолданылады.

## Ең сенімді режим

Университет аппаратында `launch-kiosk.bat` арқылы ашыңыз. Edge `--kiosk-printing` режимімен іске қосылады.

Егер сайтты кәдімгі Edge/Chrome терезесінен Ctrl+P арқылы бассаңыз, print dialog ішінде **Headers and footers / Колонтитулы** өшірулі екенін тексеріңіз. Бұл браузердің жеке параметрі және сайт оны барлық браузер нұсқасында мәжбүрлі түрде өзгерте алмайды.

## Түпнұсқаны тексеру

Әр өтініште **Түпнұсқа PDF / Оригинальный PDF** батырмасы бар. Ол дәл сол өтінішке арналған source PDF беттерін ашады.
